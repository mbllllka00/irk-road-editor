# Редактор графа УДС (OSM → правки → OSM)

Веб-приложение: TypeScript + Vite + MapLibre GL. Бэкенда нет, файл открывается и сохраняется в браузере.

```bash
npm install
npm run dev            # разработка, http://localhost:5173
npm test               # тесты ядра, операций и валидатора (node:test)
npm run build          # продакшн-сборка в dist/

docker build -t irk-editor .
docker run -p 8080:80 irk-editor    # http://localhost:8080
```

Сохранённый файл называется `<имя в поле слева от «Сохранить»>.osm` — по заданию оно должно совпадать с именем команды.

## Линии и метки «по смыслу»

Режим «Метка» (`T`): выберите тип в верхней панели (скорость, полосы, направление, покрытие, лестница, переход, «Уступи», «Стоп») и кликайте по линии. Участки задаются двумя кликами (начало и конец), переходы и знаки одним. Движок сам режет рёбра, ставит теги и склеивает одинаковые куски обратно. Режим «Участок» (`U`): начало и конец на линии, затем новая форма, Enter. Атрибуты сохраняются, боковые улицы пристыковываются сами. При сохранении выполняется автоматика: канонизация oneway, склейка рёбер, полосы по направлениям (`lanes:forward/backward`), `lane_markings`.

## Раскраска, покрытие, скорость

Переключатель «Раскраска» (клавиша `K`): класс дороги (главные жёлтые, пешеходные и трамвай пунктиром), число полос, покрытие, ограничение скорости. Легенда слева на карте показывает, сколько рёбер в каждой категории. В панели свойств у выбранных рёбер (одного или многих) есть выбор класса, покрытия и кнопки скорости.

## Что проверено и что нет

Проверено: парсинг-независимая логика (ops, валидатор, сериализатор) покрыта тестами `tests/core.test.ts`; типы ядра и UI проходят `tsc`.
**Не проверено** (в среде без сети нельзя было установить зависимости): сборка Vite, реальная работа MapLibre в браузере, `DOMParser`-парсер на `example.osm`. Первым делом P1 запускает `npm install && npm run dev` и открывает `example.osm`; вероятные места правок — стили слоёв в `mapView.ts`.

## Известные ограничения

- «Кому уступаем»: в OSM приоритет по конкретной дороге выразить нельзя. Редактор находит нужный перекрёсток, ставит знак за 5 м до него с `direction` и записывает адресата в `note`; предупреждает, если уступаем дороге более низкого класса.
- Переход ставится как узел `highway=crossing` на линии. Отдельные рёбра `footway=crossing` между тротуарами через проезжую часть пока не создаются.

- Relations при split/merge обновляются упрощённо (restriction-отношения с `via`-way проверьте вручную).
- 3D — наклон камеры и выдавленные здания; ленты проезжей части и мосты в 3D не строятся.
- Подложки 2ГИС/Яндекс/Google подключаются как XYZ-URL в поле «Свои тайлы»; лицензии проверяйте сами.
- Автосохранения нет: перед закрытием вкладки браузер спросит подтверждение.
