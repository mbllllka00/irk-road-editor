# Редактор графа УДС (OSM → правки → OSM)

Веб-приложение: TypeScript + Vite + MapLibre GL. Бэкенда нет, файл открывается и сохраняется в браузере.

```bash
npm install
npm run dev            # разработка, http://localhost:5173
npm test               # тесты ядра, операций и валидатора (node:test)
npm run build          # продакшн-сборка в dist/

docker build -t irk-editor .
docker run -p 8080:80 irk-editor    # http://localhost:8080
```

Сохранённый файл называется `<имя в поле слева от «Сохранить»>.osm` — по заданию оно должно совпадать с именем команды.

## Линии и метки «по смыслу»

Режим «Метка» (`T`): выберите тип в верхней панели (скорость, полосы, направление, покрытие, лестница, переход, «Уступи», «Стоп») и кликайте по линии. Участки задаются двумя кликами (начало и конец), переходы и знаки одним. Движок сам режет рёбра, ставит теги и склеивает одинаковые куски обратно. Режим «Участок» (`U`): начало и конец на линии, затем новая форма, Enter. Атрибуты сохраняются, боковые улицы пристыковываются сами. При сохранении выполняется автоматика: канонизация oneway, склейка рёбер, полосы по направлениям (`lanes:forward/backward`), `lane_markings`.

## Раскраска, покрытие, скорость

Переключатель «Раскраска» (клавиша `K`): класс дороги (главные жёлтые, пешеходные и трамвай пунктиром), число полос, покрытие, ограничение скорости. Легенда слева на карте показывает, сколько рёбер в каждой категории. В панели свойств у выбранных рёбер (одного или многих) есть выбор класса, покрытия и кнопки скорости.

## Что проверено и что нет

Проверено: парсинг-независимая логика (ops, валидатор, сериализатор) покрыта тестами `tests/core.test.ts`; типы ядра и UI проходят `tsc`.
**Не проверено** (в среде без сети нельзя было установить зависимости): сборка Vite, реальная работа MapLibre в браузере, `DOMParser`-парсер на `example.osm`. Первым делом P1 запускает `npm install && npm run dev` и открывает `example.osm`; вероятные места правок — стили слоёв в `mapView.ts`.

## Известные ограничения

- «Кому уступаем»: в OSM приоритет по конкретной дороге выразить нельзя. Редактор находит нужный перекрёсток, ставит знак за 5 м до него с `direction` и записывает адресата в `note`; предупреждает, если уступаем дороге более низкого класса.
- Переход ставится как узел `highway=crossing` на линии. Отдельные рёбра `footway=crossing` между тротуарами через проезжую часть пока не создаются.

- Relations при split/merge обновляются упрощённо (restriction-отношения с `via`-way проверьте вручную).
- 3D — наклон камеры и выдавленные здания; ленты проезжей части и мосты в 3D не строятся.
- Подложки 2ГИС/Яндекс/Google подключаются как XYZ-URL в поле «Свои тайлы»; лицензии проверяйте сами.
- Автосохранения нет: перед закрытием вкладки браузер спросит подтверждение.


## Дополнительные функции (доработка)

- **Генератор кольцевого перекрёстка**: кнопка «+ Кольцо» запрашивает радиус, число сегментов, полосы и скорость, затем создаёт замкнутый OSM way с `junction=roundabout` и `oneway=yes`. Въезды/выезды после создания нужно соединить инструментом «Ребро».
- **Автоисправление точных дубликатов узлов**: кнопка объединяет пары узлов, которые валидатор сгруппировал по координатам и расстояние между которыми дополнительно проверено (менее 0,2 м). Перед операцией показывается подтверждение; действие можно отменить через Undo. Автоматически близкие, но не совпадающие координаты не объединяются, чтобы не менять геометрию без согласия пользователя.
- **Статистика сети**: выводит количество узлов, дорог, отношений, односторонних участков, мостов, тоннелей, светофоров, переходов, незаданных полос/скоростей и размер крупнейшей неориентированной компоненты.
- **Защита экспорта**: критические ошибки валидатора блокируют сохранение; предупреждения требуют подтверждения. Это снижает риск отправки файла с повреждёнными ссылками или некорректной топологией.

Генератор кольца создаёт геометрию, но не рисует автоматически подъезды: их следует соединить с существующей сетью и повторно выполнить проверку. Автоисправление ограничено точными дубликатами координат; оно не пытается самостоятельно угадывать, какие близкие узлы являются одним перекрёстком.

## Правки v2

- **Множественное выделение**: Shift+клик не работал, потому что MapLibre по умолчанию отдаёт Shift+клик под zoom-рамку и подавляет click (`boxZoom` отключён). Теперь: Shift/Ctrl+клик, Shift+рамка (режим «Выбор»), кнопка «☑ Мульти».
- **Подсветка по видам дорог**: в раскраске «класс» у каждого значения `highway` свой цвет (22 категории), съезды — светлый оттенок родительского класса. Клик по строке легенды подсвечивает только эту категорию (Esc — сброс).
- **Съезды**: пять `*_link` сгруппированы в списке класса, в панели есть справка «чем отличаются», для выбранного съезда показано, какие дороги к нему примыкают и какой класс подходит (`recommendLink`).
- **Светофоры**: иконка светофора с ореолом на перекрёстках, красная пунктирная — светофор вне перекрёстка, отдельные иконки для регулируемого/нерегулируемого перехода, обозначения со счётчиками в легенде.
- **Легенда** скрывается кнопкой над ней или клавишей `G` (запоминается). **Фильтр ошибок**: по тяжести и по типу проверки, отфильтрованное же подсвечивается на карте. **Название улицы** выбранных рёбер показывается подписью на карте и в заголовке панели.
- **Парковка**: тип «Парковка: проезд между местами» (`highway=service` + `service=parking_aisle`) в списке класса и в шаблонах, своя раскраска; замкнутые контуры `amenity=parking` рисуются полупрозрачной заливкой для ориентира.
- **Копирование характеристик**: Alt+C на одном ребре запоминает, Alt+V вставляет в выбранные; на нескольких рёбрах Alt+C копирует с первого выбранного. Копируются highway, service, oneway, lanes*, maxspeed*, surface и др., но не name/bridge/ele.
- **Подложка OSM**: добавлен `referrer`-мета (серверы OSM требуют Referer). Не открывайте собранный `dist/` через `file://`: запускайте через `npm run dev` или Docker.
- **Кольцо как в Paint**: «+ Кольцо» → зажать кнопку и тянуть рамку от угла к углу, предпросмотр виден сразу; Shift (или галочка «всегда круг») — ровный круг; простой клик — кольцо радиуса R. Узлы идут против часовой стрелки (правостороннее движение; раньше шли по часовой).
- **Ошибки в выделении**: в панели свойств сверху показаны замечания именно для выбранных рёбер/узлов; в списке ошибок есть переключатель «Только выделенное».
- **Время максимальной загрузки**: поле `peak_hours` (`07:30-09:30;17:00-19:00`) в панели ребра, метка «Время макс. загрузки» в режиме `T`, проверка формата валидатором. Тег нестандартный: SUMO/MatSim его игнорируют.
- **Статистика** открывается в окне с кнопками сохранения в .txt, .csv и .json (имя: `<имя команды>_stats.*`); добавлены длина сети и разбивка по классам и типам ошибок.
- **Поиск улицы**: поле «Поиск улицы…» в шапке (клавиша `/`), подсказки с числом рёбер; Enter выделяет все рёбра с таким `name` и приближает карту. Если точного совпадения нет, ищется по вхождению.
- **Подземный пешеходный переход**: `highway=footway` + `tunnel=yes` + `layer=-1`. На карте тёмно-фиолетовая подсветка, фиолетовый пунктир и значок со стрелкой вниз, своя строка в легенде. Задаётся в списке класса, шаблоном или меткой «Подземный пеш. переход». Тоннели `building_passage` и автомобильные тоннели подземкой не считаются.

## Доработки: плавное перемещение и сравнение с исходным OSM

- **Перетаскивание узлов/дорог**: обновление затронутых геометрий через `GeoJSONSource.updateData` не чаще одного кадра; панель, легенда и валидатор больше не пересчитываются на каждом движении мыши. При отпускании мыши сохраняется один шаг Undo, выполняется полная синхронизация и проверка. Обычный клик по узлу не начинает drag (порог 3 px).
- **Сравнить с исходным**: кнопка в верхней панели включает цветной режим **непосредственно на карте**: неизменённые дорожные рёбра и узлы — серые, добавленные — зелёные, удалённые — красные (удалённые рёбра пунктиром на исходных координатах), изменённые — синие. На мелком масштабе отображаются только изменённые узлы; серые узлы появляются при приближении (z14+), чтобы не загромождать карту. Справа поверх карты отображаются легенда, счётчики, кнопка «Подробный отчёт» (изменения узлов, рёбер и отношений, экспорт `*_changes.json`) и кнопка выхода. Повторное нажатие верхней кнопки возвращает стандартную раскраску. **Единственная база сравнения — открытый исходный `.osm`**: сохранение/Undo не заменяют её, при открытии другого файла база обновляется. Сравнение не меняет OSM. После правок или Undo подсветка обновляется автоматически. При переходе к инструментам рисования цветной режим закрывается.
- Проверка логики: `npm test` (требуется Node.js 22.6+ с поддержкой `--experimental-strip-types`).
