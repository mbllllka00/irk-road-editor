# Зачем каждая фича (жюри оценивает аргументацию)   [P5 + автор фичи]

| Фича | Ценность | Метрика/пример |
|---|---|---|
| Валидатор + подсветка | находит дефекты, которые ломают потоки в MatSim/SUMO | N ошибок до → N после |
| Проверка связности (SCC) перед сохранением | не даёт отправить граф, по которому нельзя проехать | % узлов в главной компоненте |
| Склейка узлов (C) | чинит разорванные перекрёстки за 2 клика | |
| Разворот/oneway (R/O) | правка направления без ручного редактирования тегов | |
| Шаблоны дорог | типовая улица одним кликом, меньше опечаток в тегах | |
| Копирование атрибутов (Alt+C), массовая правка | 50 рёбер одной операцией | |
| Подложка со слайдером | сравнение графа с реальностью на одном экране | |
| Hotkeys + справка | скорость правки | |
| Undo/redo | безопасные эксперименты | |
| Псевдо-3D | быстрый взгляд на мосты и здания перед Webots | |
| Docker | запуск одной командой, без сборки окружения | |
